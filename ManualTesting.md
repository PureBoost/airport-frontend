# Manual Testing Scenarios

### Test 1: User Login

**User Story:**  
As a user, I want to log in so that I can access the application.

**Steps:**
1. Open the login page.
2. Enter valid login credentials.
3. Click the Login button.

**Expected Result:**  
The user is successfully logged in and redirected to the application.

**Actual Result:**  
The user was successfully logged in and redirected to the application.

---

### Test 2: Invalid Login

**User Story:**

**Steps:**
1. Open the login page.
2. Enter invalid login credentials.
3. Click the Login button.

**Expected Result:**  
An error message is displayed and the user is not logged in.

**Actual Result:**  
An error message was displayed and the user was not logged in.

### Test 4: Create a Flight

**User Story:**  
As an administrator, I want to create a flight so that new flights can be added to the system.

**Steps:**
1. Navigate to the Admin page.
2. Select Flights.
3. Enter the flight information.
4. Select an airport.
5. Select an airline.
6. Select an aircraft.
7. Select a gate.
8. Select the type
9. Select the status
10. Click Add Flight.

**Expected Result:**  
The flight is created and appears in the flight list.

**Actual Result:**  
The flight was created and appeared in the flight list.
